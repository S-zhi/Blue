# 自动语音感知

浏览器负责采音、本地阈值检测及字幕。BFF 使用服务端 `.env` 的 `DOUBAO_API_KEY` 连接豆包双向流式接口，密钥不进入前端。默认模型 2.0，开启年龄、性别声线、情绪及说话人信息。

## 启动与前台检测

`npm run dev` 启动开发服务；生产构建用 `npm run build` 后 `npm start`。浏览器必须支持 AudioWorklet，并通过 localhost 或 HTTPS 访问。首次需要允许麦克风；若浏览器阻止 AudioContext 自动运行，顶部显示一次性的授权入口。

页面可见且 `document.hasFocus()` 时自动进入本地感知。连续 60 ms 音量超过自适应阈值后连接云端，保留触发前约 500 ms 音频；连接期间缓存上限约 12 秒，超出会报错停止。待命时不上传音频。页面失焦、切换标签或隐藏即释放麦克风并断开，回到前台重新感知。这是浏览器可检测的前台条件，无法可靠判断窗口是否被其他窗口局部遮挡。

单轮识别结束后自动回到本地感知，无需逐轮点击。错误不会无限重试，顶部显示重试入口。声音阈值是能量检测，音乐和持续噪声也可能触发。

## 结束与字幕

云端连接就绪后启动 10 秒期限，**只有非空识别文字发生变化才重新计时**；音量变化、背景噪声、重复回包及单纯的属性更新不会延期。连续 10 秒没有新文字就刷新尾包并请求最终结果。云端 800 ms 分句与本地结束期限独立，单次识别仍有 120 秒上限。

字幕区域只保留透明背景上的文字，宽度为视口 78%，最大 1100px。每次文字更新后显示 30 秒，相同文字不会续期；新一轮的首个结果可以替换旧字幕。年龄、声线与情绪在右侧展示，均仅为模型估计。

圆环随情绪平滑变色：平静冰蓝、开心青绿、悲伤淡紫、生气珊瑚红、惊讶浅金。情绪色彩仅为视觉表达，不代表安全等级。未返回新情绪时保留最近一次有效颜色。

语音整轮最终结果现在自动交给 Agent/MCP 执行，每轮只提交一次。临时字幕、模型回答与执行错误通过统一字幕渲染器显示，输入蓝色无衬线、回答浅白衬线，逐字显示后保留 30 秒。只有麦克风不可用才开放文字输入，文字输入跳过 ASR，执行结果仍回到字幕。模型 520 等错误会显示在字幕上，不冒充执行成功；新一轮仍可继续。

## 验证及部署

`npm test` 测试重采样、协议、BFF 状态机、文本期限和字幕保留；禁止监听端口的环境会跳过两项 WebSocket 集成测试。真实麦克风、浏览器焦点切换和云端响应仍需现场验证。

生产仅提供 dist；服务默认监听 127.0.0.1。公网部署需 HTTPS/WSS、登录鉴权及限流网关，设置精确 `ASR_ALLOWED_ORIGINS`，Origin 检查不能替代身份认证。服务器 ws 代码是已安装 Vite 中的 MIT 离线快照，许可见 server/vendor/ws-LICENSE.txt。
