# 点击式语音对话

浏览器负责采音、本地阈值检测及字幕。BFF 使用服务端 `.env` 的 `DOUBAO_API_KEY` 连接豆包双向流式接口，密钥不进入前端。默认模型 2.0，开启年龄、性别声线、情绪及说话人信息。

## 点击开始与停止

`npm run dev` 启动开发服务；生产构建用 `npm run build` 后 `npm start`。浏览器必须支持 AudioWorklet，并通过 localhost 或 HTTPS 访问。

页面加载、点击其他区域、返回前台或语音播报结束均不会申请或启动麦克风。点击圆环中心开始当前一轮监听，第一次使用需允许麦克风权限；再次点击停止采音、发送尾包，并等待豆包返回最终结果。圆环按钮支持键盘操作，显示监听、结束中及重试状态。

点击开始后仍使用原有豆包识别和本地语音检测：连续 60 ms 音量超过自适应阈值后连接云端，保留触发前约 500 ms 音频；连接期间最多缓存约 12 秒。连接尚未就绪时点击停止会立即释放麦克风，待连接就绪后发送已缓存音频和尾包。页面失焦或隐藏会释放麦克风，返回时需要重新点击。

## 结束与对话历史

移除连续 10 秒没有新文字便自动结束的逻辑，由第二次点击结束当前轮。云端 800 ms 分句保持不变，连接就绪后仍有 120 秒单次识别上限，结束后不会自动重新监听。

首条字幕出现后，圆环缩小并上移，中间区域展示本次对话。识别中的修订更新当前消息，新的问答追加到记录中。字幕不再定时消失，支持鼠标滚轮和键盘查看历史；向上滚动时新字幕不会抢走阅读位置，可点击“回到最新”。记录仅存在本页面内存，刷新或关闭后清空，不跨会话保存。年龄、声线与情绪继续在右侧展示，均仅为模型估计。

圆环随情绪平滑变色：平静冰蓝、开心青绿、悲伤淡紫、生气珊瑚红、惊讶浅金。情绪色彩仅为视觉表达，不代表安全等级。未返回新情绪时保留最近一次有效颜色。

语音整轮最终结果现在自动交给 Agent/MCP 执行，每轮只提交一次。临时字幕、模型回答与执行错误通过统一字幕渲染器显示，输入蓝色无衬线、回答浅白衬线，回答由 TTS 播报，并根据实际音频播放进度更新字幕；播放失败时保留完整文字及错误提示。只有麦克风不可用才开放文字输入，文字输入跳过 ASR，执行结果仍回到字幕。模型 520 等错误会显示在字幕上，不冒充执行成功；新一轮仍可继续。

## 验证及部署

`npm test` 测试重采样、协议、BFF 状态机、点击启停、字幕历史和音频同步；禁止监听端口的环境会跳过两项 WebSocket 集成测试。真实麦克风、浏览器焦点切换和云端响应仍需现场验证。

生产仅提供 dist；服务默认监听 127.0.0.1。公网部署需 HTTPS/WSS、登录鉴权及限流网关，设置精确 `ASR_ALLOWED_ORIGINS`，Origin 检查不能替代身份认证。服务器 ws 代码是已安装 Vite 中的 MIT 离线快照，许可见 server/vendor/ws-LICENSE.txt。
