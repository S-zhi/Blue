# 流式语音识别接入说明

## 架构选择

采用 BFF：浏览器 → 同源 `/api/asr` WebSocket → 豆包双向流式接口。

前端承担麦克风权限、采样、重采样、PCM 分包、本地声音触发、实时字幕和圆环交互。BFF 只承担鉴权、二进制协议编解码、响应整理与会话限制，不执行识别模型。

不直连云端的原因：浏览器原生 WebSocket 无法设置文档要求的 `X-Api-Key`、`X-Api-Resource-Id` 等自定义握手头；把长期 API Key 放入前端还会暴露给访问者。密钥只能通过服务端 `.env` 或运行环境读取，不能改成 `VITE_DOUBAO_API_KEY`。开发服务及生产服务均只默认监听 `127.0.0.1`。

## 配置及启动

在现有 `.env` 中保留 `DOUBAO_API_KEY`，其余变量参见 `.env.example`。默认：

- `wss://openspeech.bytedance.com/api/v3/sauc/bigmodel_async`
- `volc.seedasr.sauc.duration`，即文档推荐的 2.0 小时版。若账号仅有 1.0 权限，可配置 `DOUBAO_RESOURCE_ID=volc.bigasr.sauc.duration`。
- `X-Api-Request-Id` 每个任务生成独立 UUID。
- `audio.format=pcm`，`codec=raw`，16 kHz、16 bit、单声道。
- `enable_itn`、`enable_punc`、`enable_ddc`、`show_utterances` 开启；`result_type=full`。
- `enable_age_detection`、`enable_gender_detection`、`enable_emotion_detection`、`enable_speaker_info` 全部开启。
- `show_speech_rate`、`show_volume` 开启。`enable_nonstream=false`，优先实时出字；云端分句静音阈值 `end_window_size=800` ms。

需要 Node.js 22.14 或更新版本：

```bash
npm run dev
# 修改 .env 后重启服务。开发页面 http://localhost:5173

npm test
npm run build
npm start
# 构建版 + BFF: http://127.0.0.1:3000
```

用户点击“开启语音”后才申请麦克风权限并开始传输。首次使用需在浏览器中允许麦克风；远程部署必须使用 HTTPS/WSS。没有配置密钥时，前端会在请求麦克风权限前给出提示。

`ASR_ALLOWED_ORIGINS` 必须包含实际页面的精确来源，包括协议和端口。默认仅放行本地开发及预览来源。正式公网部署应由已有登录鉴权和限流网关保护 `/api/asr`，仅配置 Origin 不能替代身份认证。反向代理需要支持 WebSocket Upgrade。

## 声音触发器

本地触发器是轻量级能量检测器，不是语义识别或精确的人声分类器：

1. **采样**：AudioWorklet 从浏览器实际采样率（常见 44.1/48 kHz）连续重采样为 16 kHz。每 320 个采样点形成 20 ms 检测帧，计算 RMS 均方根音量。波形不会接到扬声器，避免自激回声。
2. **自适应底噪**：仅在未讲话且音量明显低于触发阈值时缓慢更新底噪估计。起声阈值为 `max(0.012, min(0.06, 底噪×3))`，退声阈值为 `max(0.007, min(0.04, 底噪×1.8))`；不同阈值形成滞回，减少边界抖动。
3. **判起与判停**：连续 60 ms 超过起声阈值，判为有声并立刻让圆环切换为脉冲；连续 600 ms 低于退声阈值，恢复环流。短暂停顿保持脉冲，单个点击声通常不足以触发。风扇、音乐或持续噪声仍可能误触发，这不代表识别成功。
4. **上传与字幕分句独立**：每 10 个检测帧合为 200 ms / 6400 字节 PCM 包。点击开启后，音频（包括静音）持续发往云端。本地触发器控制脉冲及会话结束，不逐帧裁切静音，因此无需靠预录缓存补回句首。云端 VAD 用 800 ms 静音做分句，并在结果中返回最终分句标记。

### 自动结束与继续说话

用户主动开启麦克风后，连续 60 ms 有声自动判起。第一次有声前不启动静音结束倒计时；首次判起后，从最后一帧超过退声阈值的声音起累计静音，600 ms 后显示等待继续说话，累计到 **10 秒** 自动结束本次输入（包含前面的 600 ms，并非再加 10 秒）。期间任一帧声音重新超过退声阈值，就立即撤销倒计时；持续 60 ms 后圆环重新进入说话脉冲。轻微噪声低于阈值不会重置，持续噪声可能延后结束。

倒计时基于实际采集的音频帧时长，与渲染 FPS 无关。自动结束沿用手动结束的尾包刷新和最终字幕确认流程，释放麦克风；下一次输入由用户重新点击开启。始终可以手动结束，2 分钟上限仍然有效。云端 800 ms 是字幕分句，不代表本地会话结束。`src/voice/timing.js` 集中定义 10 秒结束与 30 秒字幕保留参数。

触发器参数在 `src/voice/audio-core.js`，云端分句参数在 `server/config.js`。使用近讲麦克风并减少环境噪声，可以降低误触发。浏览器的回声消除、降噪和自动增益也已请求开启，但实际是否生效由设备和浏览器决定。

## 字幕与属性

- 全量结果替换当前字幕，不能把每个回包简单追加，否则会出现重复文字。
- 若最终回包只有结束标记、不包含识别文本，保留最近一次完整字幕及其属性，避免结束时字幕被清空。
- 临时字幕显示为蓝色，`definite=true` 的分句及最终结果显示为浅白色。云端可能修订临时文字，这是预期行为。
- 字幕行背景完全透明，无黑色遮罩、毛玻璃或容器阴影，字体保留原有可读性。年龄、性别声线和情绪移到右侧，语音模式下替换 FPS 和帧率历史。
- 每次文本内容改变后保留 **30 秒**，到期清空文字；相同文本的重复回包、仅确定状态变化或属性更新不延长时间，也不会使过期字幕重新出现。开启下一次识别不会提前清空上一次字幕，新文字到达时替换；手动清空和离开页面立即清除。
- 年龄取分句 `additions.age`；声线标签取 `gender`；情绪取 `emotion`；说话人取 `speaker_id`。最新分句没有返回属性时显示等待/未返回，不沿用上一位说话人的属性。
- 年龄为声学年龄估计；male/female 在界面显示为男声/女声，不是身份性别判断；情绪同样仅为模型标签。没有字段就不展示推测，也不会据此触发安全警报。

## 停止、限制与隐私

点击“结束识别”时：刷新 AudioWorklet 尾帧 → 发送不足 200 ms 的剩余 PCM → 释放麦克风 → 发送最终音频标记 → 等待云端最终结果。停止采音不等于立即关闭 WebSocket；过早断开会丢失最后几个字及声学属性。

单次录音最多 120 秒，BFF 最多同时 2 个会话。上下行缓冲超过 128 KiB 时中止并提示，避免积累过时音频。网络断开、权限撤销、超时、离开页面都会释放麦克风，不自动重连或重新录音。当前字幕会保留，用户可主动清空。应用不把录音或转写写入服务端文件，也不在日志输出密钥或音频；云端处理遵循所用服务的政策。

开发和构建资源中不应包含密钥。Vite 禁止通过静态路径访问 `.env` 和 `server/`；生产服务器只提供 `dist/`，不会提供项目根目录。

## 协议与依赖

`server/protocol.js` 使用 v1 二进制帧、gzip 请求体、客户端配置帧和音频末包标记，并处理云端正/负序号、gzip/原始 JSON 与错误帧。提供的文档示例通过 SDK 包装了二进制细节；仍需真实服务端联调确认账号和协议的兼容性。

网络依赖安装被审批服务故障阻塞，因此当前服务器复用了**项目已安装 Vite 5.4.21 中随附的 MIT ws 实现**，离线保存到 `server/vendor/ws.js`，仅调整模块包装方式，许可在相邻 `ws-LICENSE.txt`。它不进入前端产物。后续可以替换成正式安装的 `ws` 依赖，不影响业务协议。

## 验证记录与边界

- 音频重采样、PCM 编码、分包、VAD 滞回、协议编码/解码、属性解析、BFF 状态机和背压处理有自动化测试。
- `test/relay.test.js` 使用本地假云端进行真实 WebSocket 集成验证；若运行环境禁止本地端口监听，明确跳过这两项，不冒充通过。
- 当前开发环境的审批服务和网络/本地监听限制阻止了真实豆包云端联调。代码构建及无需监听端口的测试可运行，API Key 的账号权限、余额、特征字段实际返回和真实麦克风识别尚需在可联网环境验证。

参数依据：用户提供的豆包双向流式识别官方文档全文，https://docs.volcengine.com/docs/DoubaoVoice/bidirectional-streaming-automatic-speech-recognition-websocket?lang=zh 。
